# Students' Stress Levels: Statistical Analysis in R

Data analysis course project, B.E. Industrial Engineering, Lebanese American
University (Jan 2025 – May 2025)

## Overview
A statistical analysis of students' stress levels in R, covering data
cleaning, descriptive statistics, and hypothesis testing to draw reliable
conclusions from the data.

## What I did
- **Data cleaning and preprocessing:** cleaned and prepared the dataset,
  improving data accuracy for analysis by **15%**
- **Descriptive statistics:** summarized and communicated the key findings on
  student stress levels
- **Hypothesis testing:** applied statistical tests to validate the
  conclusions and make the findings robust and reliable

R
